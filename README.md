
# To-Do List Application (Console-Based)

## Objective
A simple Python-based To-Do List Manager that allows users to manage daily tasks.

## Technologies Used
- Python
- VS Code
- File Handling

## Features
- Add new tasks
- View all tasks
- Remove tasks
- Save tasks in a text file
- Load saved tasks when restarting the application

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python todo.py

## Project Files
- todo.py - Main Python application.
- tasks.txt - Stores saved tasks (created automatically).

## Conclusion
This project demonstrates Python lists, functions, loops, conditional statements and file handling.
